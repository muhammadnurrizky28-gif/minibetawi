# Tabel Simbol BetawiCode

## Pengertian

Tabel simbol digunakan untuk menyimpan informasi mengenai variabel yang telah dideklarasikan selama proses Semantic Analysis.

## Struktur Tabel Simbol

| Nama Variabel | Tipe Data | Nilai |
| ------------- | --------- | ----- |
| nama          | string    | Rizky |
| umur          | integer   | 20    |
| status        | boolean   | bener |

## Contoh Source Code

```betawi
nama = "Rizky"
umur = 20
status = bener
```

## Hasil Tabel Simbol

| Nama   | Tipe    | Nilai |
| ------ | ------- | ----- |
| nama   | string  | Rizky |
| umur   | integer | 20    |
| status | boolean | True  |

## Fungsi Tabel Simbol

1. Menyimpan variabel yang telah dideklarasikan.
2. Memeriksa penggunaan variabel yang belum dibuat.
3. Membantu proses Semantic Analysis.
4. Menentukan tipe data setiap variabel.
